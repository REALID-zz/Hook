# 运营与技术运维（最小方案）

## 1) 日志与审计留痕（防“被抓漏洞”）

- 记录关键事件：发帖、删帖、举报、封禁、聊天风控拦截、支付状态变更（如开通）\n- 保留证据链：事件时间、用户ID（或匿名ID）、IP（必要时）、相关对象ID（postId/orderId）\n- 保留周期：按地区法规与业务需要设定（建议 180 天起，公益/交易可能更长）\n
## 2) 监控

- 关键指标：\n  - 请求成功率、延迟、5xx\n  - WebSocket 在线连接数、消息速率、拦截率\n  - 发帖/举报/封禁数量\n- 告警：端口不可用、数据库不可用、异常激增\n
## 3) 风控配置（可热更新）

- 限频：发帖/私聊/WS\n- 敏感词表：诈骗/金融/隐私/虚拟币\n- 黑名单：设备/IP/账号\n
## 4) 数据备份

- SQLite 首版：每日备份文件到安全位置\n- 上线：建议迁移到 Postgres，并开启自动备份与主从/高可用\n
