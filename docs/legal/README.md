# 法务与合规文档（草案）

这些文档是**产品落地所需的条款/政策草案**，用于尽早把责任边界、风控与信息披露写清楚，降低“被恶意竞争抓漏洞”的风险。

> 重要：这些内容不是法律意见；上线前建议让当地律师按中国大陆/港澳台/美国分别审阅。

- `terms.md`: 服务条款（ToS）
- `privacy.md`: 隐私政策（含定位/聊天/日志）
- `content-policy.md`: 内容与社区规范（含反诈骗/反骚扰/未成年人）
- `marketplace-policy.md`: 市集交易规则（抽成披露、禁售、争议、退款）
- `charity-policy.md`: 公益模块规则（资质、披露、捐赠入口、费用）
- `safety.md`: 人身安全与线下互动安全指引
