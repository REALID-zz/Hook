# 服务条款（草案）

- 你需对账号下的所有行为负责。\n- 平台可提供匿名/轻注册，但对某些高风险功能（例如交易、提现、线下活动）可要求更高等级的验证。\n- 你不得冒用他人身份，不得协助他人规避监管或风控。

## 3. 禁止行为（重点）

你不得使用服务从事包括但不限于以下行为：

- **诈骗、洗钱、恐吓、骚扰、跟踪**等违法行为\n- 发布他人隐私信息（包括定位轨迹、身份证件、联系方式等）\n- 发布或引导交易**加密货币/虚拟货币**、私钥、助记词等高风险金融信息（中国大陆尤其禁止）\n- 发布违禁品交易信息（武器、毒品、管制药品等）\n- 诱导未成年人线下见面或发布不适宜未成年人的内容\n
平台可对违规内容采取删除、限流、禁言、封号、配合执法等措施。

## 4. 互动与线下见面

- 你理解线下互动存在风险，应优先选择公共场所、白天时段、多人同行；不得强迫他人线下见面。\n- 对“失物招领”建议使用平台提供的验证流程（问题验证/局部图）并在公共场所交接。\n- 平台可对敏感时间/地点/标签的邀约进行降权或禁止发布。
