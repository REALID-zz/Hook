# 人身安全与线下互动安全指引（草案）

## 1. 核心原则

- 优先公共场所、白天时段、多人同行\n- 保护隐私：不要泄露家庭住址、身份证、验证码等\n- 对失物交接：先验证再交接，尽量在监控覆盖区域\n
## 2. 邀约安全

- 建议先群聊沟通，确认目的与规则\n- 不接受强迫性邀约\n- 发现异常立即退出并举报\n
## 3. 失物招领安全

- 使用“验证问题”（只有失主知道的细节）\n- 图片建议局部图，不要暴露序列号全量\n- 不要先转账给“好心人”\n
## 4. 紧急情况

- 遇到人身危险、敲诈勒索、诈骗、暴力威胁：立即联系当地警方/急救\n- 平台可提供举报与证据留存，但不替代执法\n
