# Web/PWA 首版线框（可点击原型的页面清单）

目标：先把“你图里那种线框风格”变成一套可跑的 Web 原型（页面之间能跳、列表能点、表单能发），便于你逐块加需求。

## 1) 全局布局（对应你图）

- **顶部栏**：左侧 Logo/站点名（“阿邦我的app”）｜右侧 `Signup/Login`｜搜索框
- **主导航 Tabs**：`互动` `失物招领` `市集交易` `公益` `项目`
- **三栏结构**：
  - 左栏：分类/Section 列表（可切换过滤）
  - 中栏：主内容（推荐流/详情/表单）
  - 右栏：同场所热点/外部链接/安全提示
- **底部卡片墙**：最近的“卡包”/徽章/作品/帖子（网格）
- **Footer**：版权/条款入口

## 2) 页面（首版必须有）

### 2.1 首页 `/`
- 选择场所（Venue）与时间窗口（默认“现在±2小时”）
- 展示“同场所实时大厅”入口（进入 `/interact?venue=`）
- 推荐流（混合：邀约+失物+项目更新+市集推荐）

### 2.2 互动大厅 `/interact`
- 顶部：当前场所 + 时间窗口 + 发布按钮
- 中栏：邀约列表（可筛选：吃饭/创作/互助）
- 右栏：同场所热门、规则与安全提示

### 2.3 发布邀约 `/interact/new`
- 表单：主题、标签、人数、是否审核加入、时间窗口、说明
- 提交后跳到 `/interact/:postId`

### 2.4 失物大厅 `/lost`
- tabs：`我丢了` / `我捡到`
- 列表：按时间窗口+场所过滤
- 系统推荐“可能匹配”（同场所+时间窗口+相似描述）

### 2.5 市集 `/market`
- 列表/网格：作品/商品
- 详情：下单按钮（首版可先做“模拟下单”）

### 2.6 公益 `/charity`
- 项目列表（带“资质/披露”标签）
- 详情页展示：资金流向、进度、凭证链接（首版可放示例）

### 2.7 项目 `/projects`
- 项目列表 + 项目详情 + 支持/打赏入口（首版可模拟）

### 2.8 消息 `/messages`
- 左：会话列表
- 右：聊天窗口（WebSocket 实时）

### 2.9 个人卡包 `/profile`
- 徽章/声誉/历史互动
- 订单/支持记录入口（首版可假数据）
